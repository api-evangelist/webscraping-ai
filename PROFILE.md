# WebScraping.AI

Web scraping and data extraction API with JavaScript rendering, rotating proxies, CAPTCHA solving, and AI-powered structured data extraction. Offers a REST API, an OpenAPI 3.1 contract, and both hosted and self-hosted MCP servers.

## APIs

- **WebScraping.AI REST API** — REST API for fetching HTML, extracting text, and AI-powered question answering and structured field extraction from webpages. Uses API-key auth via query parameter. (`https://api.webscraping.ai`)
- **WebScraping.AI Hosted MCP Server** — Hosted Model Context Protocol server connecting WebScraping.AI directly to AI assistants like Claude, Cursor, and Windsurf. Sign in with account, no API key needed. Tools mirror the REST endpoints. (`https://mcp.webscraping.ai/mcp`)
